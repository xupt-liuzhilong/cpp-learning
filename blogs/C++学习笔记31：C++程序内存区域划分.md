# C++学习笔记31：C/C++程序内存区域划分

## 一、为什么要学习内存区域？

在学习 C/C++ 内存管理之前，首先要知道程序运行时内存大概分成哪些区域。

因为后面会经常遇到这些问题：

```
局部变量在哪里？
全局变量在哪里？
static变量在哪里？
malloc申请的空间在哪里？
指针变量本身在哪里？
指针指向的内容在哪里？
字符串常量在哪里？
```

如果这些分不清，后面学习 `malloc/free`、`new/delete` 时就很容易混。

------

## 二、先看一段代码

```cpp
#include <iostream>
#include <cstdlib>
using namespace std;

int globalVar = 1;
static int staticGlobalVar = 1;

void Test()
{
    static int staticVar = 1;
    int localVar = 1;

    int num1[10] = { 1, 2, 3, 4 };
    char char2[] = "abcd";
    const char* pChar3 = "abcd";

    int* ptr1 = (int*)malloc(sizeof(int) * 4);
    int* ptr2 = (int*)calloc(4, sizeof(int));
    int* ptr3 = (int*)realloc(ptr2, sizeof(int) * 4);

    free(ptr1);
    free(ptr3);
}
```

问题：

```text
globalVar在哪里？  	staticGlobalVar在哪里？ 
staticVar在哪里？  	localVar在哪里？ 
num1 在哪里？

char2在哪里？   	pChar3在哪里？
ptr1在哪里？ 		*char2在哪里？ 
*pChar3在哪里？ 	*ptr1在哪里？
```

------

## 三、C/C++常见内存区域

程序运行时，常见内存区域可以简单分为：

```
栈区
堆区
数据段
代码段
```

对应关系可以先这样记：

```
栈区：局部变量、函数参数、局部数组
堆区：malloc / calloc / realloc / new 申请的空间
数据段：全局变量、静态变量
代码段：可执行代码、字符串常量等只读数据
```

------

## 四、变量存储位置分析

### 1. globalVar 在哪里？

```cpp
int globalVar = 1;
```

`globalVar` 是全局变量。

所以它存放在：

```
数据段
```

------

### 2. staticGlobalVar 在哪里？

```cpp
static int staticGlobalVar = 1;
```

`staticGlobalVar` 是全局静态变量。

它也存放在：

```
数据段
```

全局变量和全局静态变量的生命周期都是整个程序运行期间。

区别主要是作用范围不同：

```
全局变量：其他文件也可能访问
全局静态变量：只能在当前文件中访问
```

------

### 3. staticVar 在哪里？

```cpp
static int staticVar = 1;
```

`staticVar` 是局部静态变量。

虽然它写在函数内部，但它不是存放在栈上，而是存放在：

```
数据段
```

局部静态变量的特点是：

```
作用域在函数内部
生命周期是整个程序运行期间
第一次执行到定义处时初始化
```

------

### 4. localVar 在哪里？

```cpp
int localVar = 1;
```

`localVar` 是普通局部变量，存放在：

```
栈区
```

函数调用时创建，函数结束后自动销毁。

------

## 五、数组和字符串分析

### 1. num1 在哪里？

```cpp
int num1[10] = { 1, 2, 3, 4 };
```

`num1` 是局部数组，定义在函数内部。

所以整个数组都存放在：

```
栈区
```

注意：数组名 `num1` 代表数组首元素地址，但这块数组空间本身是在栈上的。

------

### 2. char2 在哪里？

```cpp
char char2[] = "abcd";
```

`char2` 是局部字符数组。

它会在栈上开辟一块数组空间，用来存放：

```cpp
'a' 'b' 'c' 'd' '\0'
```

所以：

```
char2 在栈区
*char2 也在栈区
```

因为 `*char2` 访问的是数组第一个元素 `'a'`，这个元素属于局部数组的一部分。

------

### 3. pChar3 在哪里？

```cpp
const char* pChar3 = "abcd";
```

这里要分开看：

```
pChar3 这个指针变量本身在栈区
"abcd" 这个字符串常量在代码段/常量区
```

也就是说：

```
pChar3 在栈区
*pChar3 在代码段/常量区
```

因为 `*pChar3` 访问的是字符串常量中的第一个字符 `'a'`。

------

## 六、malloc、calloc、realloc 分析

### 1. ptr1 在哪里？

```cpp
int* ptr1 = (int*)malloc(sizeof(int) * 4);
```

这里也要分开看：

```
ptr1 这个指针变量本身是局部变量，在栈区
malloc申请出来的空间在堆区
```

所以：

```
ptr1 在栈区
*ptr1 在堆区
```

因为 `*ptr1` 访问的是 malloc 申请的堆空间。

------

### 2. ptr2 和 ptr3 怎么理解？

```cpp
int* ptr2 = (int*)calloc(4, sizeof(int));
int* ptr3 = (int*)realloc(ptr2, sizeof(int) * 4);
```

`ptr2` 和 `ptr3` 本身都是局部指针变量，所以它们在：

```
栈区
```

但是它们指向的空间来自 `calloc` 或 `realloc`，所以指向的内容在：

```
堆区
```

需要注意：

```
ptr3 = (int*)realloc(ptr2, sizeof(int) * 4);
```

`realloc` 可能会在原来的空间上扩容，也可能重新找一块空间。

所以后面释放时释放的是：

```
free(ptr3);
```

而不是再释放 `ptr2`。

------

## 七、这道题整理

根据上面的代码，可以得到：

| 变量/表达式       | 存储位置      | 原因                   |
| ----------------- | ------------- | ---------------------- |
| `globalVar`       | 数据段        | 全局变量               |
| `staticGlobalVar` | 数据段        | 全局静态变量           |
| `staticVar`       | 数据段        | 局部静态变量           |
| `localVar`        | 栈区          | 普通局部变量           |
| `num1`            | 栈区          | 局部数组               |
| `char2`           | 栈区          | 局部字符数组           |
| `*char2`          | 栈区          | 访问的是局部数组元素   |
| `pChar3`          | 栈区          | 局部指针变量           |
| `*pChar3`         | 代码段/常量区 | 访问的是字符串常量     |
| `ptr1`            | 栈区          | 局部指针变量           |
| `*ptr1`           | 堆区          | 访问 malloc 申请的空间 |

------

## 八、指针变量和指向空间要分开看

这道题最容易错的地方是把：

```
指针变量本身
指针指向的空间
```

混在一起。

例如：

```cpp
int* ptr1 = (int*)malloc(sizeof(int) * 4);
```

不能简单说 `ptr1` 在堆上。

准确说法是：

```
ptr1 本身是局部变量，在栈上；
ptr1 指向的 malloc 空间在堆上。
```

再比如：

```cpp
const char* pChar3 = "abcd";
```

准确说法是：

```
pChar3 本身在栈上；
字符串常量 "abcd" 在代码段/常量区；
*pChar3 访问的是字符串常量中的字符，所以在代码段/常量区。
```

所以分析这类题时，要先问自己一句：

> 现在问的是变量本身，还是变量指向的内容？

------

## 九、小结

本篇主要通过一道代码题整理了 C/C++ 程序的内存区域划分。

需要记住：

1. 普通局部变量一般在栈区；
2. 局部数组也在栈区；
3. 全局变量在数据段；
4. 静态变量在数据段；
5. `malloc/calloc/realloc` 申请的空间在堆区；
6. 指针变量本身在哪里，取决于它定义的位置；
7. 局部指针变量一般在栈区；
8. 指针指向的内容可能在堆区，也可能在代码段；
9. 字符数组 `char arr[] = "abcd"` 的内容在数组空间中；
10. 字符指针 `const char* p = "abcd"` 指向的是字符串常量；
11. 分析内存位置时，一定要区分“变量本身”和“指向的内容”。
