# C++学习笔记36：函数模板入门

## 一、为什么需要模板？

在 C 语言中，如果要交换两个变量的值，可能会写一个 `Swap` 函数。

交换 `int`：

```cpp
void Swap(int& x, int& y)
{
    int tmp = x;
    x = y;
    y = tmp;
}
```

如果要交换 `double`，还要再写一个：

```cpp
void Swap(double& x, double& y)
{
    double tmp = x;
    x = y;
    y = tmp;
}
```

如果要交换 `char`，还要继续写：

```cpp
void Swap(char& x, char& y)
{
    char tmp = x;
    x = y;
    y = tmp;
}
```

可以发现，这几个函数的逻辑完全一样：

```cpp
定义临时变量
交换 x 和 y
```

区别只是类型不同。

如果每种类型都写一份，代码就会非常重复。

这时候就可以使用 **模板**。

------

## 二、模板的作用

模板的作用是：

> 写一份和具体类型无关的代码，让编译器根据实际类型自动生成对应版本。

比如交换两个变量，不管是 `int`、`double` 还是 `char`，交换逻辑都一样。

我们希望只写一份：

```cpp
Swap(x, y);
```

然后让编译器根据传入参数的类型，自动生成对应函数。

这就是模板的意义。

模板体现的是 C++ 中的 **泛型编程** 思想。

所谓泛型编程，就是：

```cpp
先不确定具体类型
把类型当成参数
等真正使用时再确定类型
```

------

## 三、函数模板的基本写法

函数模板的基本格式是：

```cpp
template <class T>
返回类型 函数名(参数列表)
{
    函数体;
}
```

也可以写成：

```cpp
template <typename T>
返回类型 函数名(参数列表)
{
    函数体;
}
```

其中：

```cpp
template：声明这是一个模板
class / typename：表示后面是一个类型参数
T：类型参数名，可以理解为一个“类型占位符”
```

`T` 不是固定必须叫 `T`，只是习惯上常用 `T` 表示 Type。

------

## 四、用模板实现 Swap 函数

使用函数模板后，交换函数可以写成：

```cpp
template <class T>
void Swap(T& x, T& y)
{
    T tmp = x;
    x = y;
    y = tmp;
}
```

这里的 `T` 可以代表任意类型。

如果调用时传入的是 `int`：

```cpp
int a = 10;
int b = 20;

Swap(a, b);
```

编译器会把 `T` 推导成 `int`。

如果调用时传入的是 `double`：

```cpp
double x = 1.1;
double y = 2.2;

Swap(x, y);
```

编译器会把 `T` 推导成 `double`。

也就是说，程序员只写了一份模板，编译器会根据使用情况生成具体函数。

------

## 五、完整示例

```cpp
#include <iostream>
using namespace std;

template <class T>
void Swap(T& x, T& y)
{
    T tmp = x;
    x = y;
    y = tmp;
}

int main()
{
    int a = 10;
    int b = 20;

    double x = 1.1;
    double y = 2.2;

    char ch1 = 'A';
    char ch2 = 'B';

    Swap(a, b);
    Swap(x, y);
    Swap(ch1, ch2);

    cout << a << " " << b << endl;
    cout << x << " " << y << endl;
    cout << ch1 << " " << ch2 << endl;

    return 0;
}
```

运行结果：

```cpp
20 10
2.2 1.1
B A
```

通过模板，一份 `Swap` 代码就可以适配多种类型。

## 六、typename 和 class 的区别

函数模板中可以写：

```cpp
template <class T>
```

也可以写：

```cpp
template <typename T>
```

在这里，`class` 和 `typename` 的作用基本一样，都是表示 `T` 是一个类型参数。

例如：

```cpp
template <class T>
void Swap(T& x, T& y)
{
    T tmp = x;
    x = y;
    y = tmp;
}
```

和：

```cpp
template <typename T>
void Swap(T& x, T& y)
{
    T tmp = x;
    x = y;
    y = tmp;
}
```

效果是一样的。

初学阶段可以简单记：

```cpp
template <class T>
template <typename T>
这两种写法都可以。
```

------

## 七、模板参数可以有多个

模板不一定只能有一个类型参数，也可以有多个。

例如：

```cpp
template <class T1, class T2>
void Print(const T1& x, const T2& y)
{
    cout << x << " " << y << endl;
}
```

调用：

```cpp
int a = 10;
double b = 3.14;

Print(a, b);
```

这里：

```cpp
T1 被推导成 int
T2 被推导成 double
```

完整示例：

```cpp
#include <iostream>
using namespace std;

template <class T1, class T2>
void Print(const T1& x, const T2& y)
{
    cout << x << " " << y << endl;
}

int main()
{
    Print(10, 3.14);
    Print("hello", 100);

    return 0;
}
```

运行结果：

```cpp
10 3.14
hello 100
```

------

## 八、函数模板的显式实例化调用

大多数情况下，编译器可以自动推导模板参数。

例如：

```cpp
int a = 1;
int b = 2;

Swap(a, b);
```

编译器能知道 `T` 是 `int`。

但也可以显式指定类型：

```cpp
Swap<int>(a, b);
```

这种写法表示：

```cpp
明确告诉编译器，这里使用 int 版本的 Swap。
```

一般初学时，直接让编译器自动推导就可以。

------

## 九、模板不是万能的

模板能提高代码复用，但也不是所有代码都能直接套模板。

比如：

```cpp
template <class T>
T Add(const T& x, const T& y)
{
    return x + y;
}
```

这个模板要求 `T` 类型支持 `+` 运算。

对于 `int`、`double` 可以：

```cpp
cout << Add(1, 2) << endl;
cout << Add(1.1, 2.2) << endl;
```

但是如果某个自定义类型没有重载 `operator+`，就不能直接使用这个模板。

所以模板的前提是：

```cpp
模板函数中使用的操作，传入类型必须支持。
```

------

## 十、模板和函数重载的关系

函数重载可以让同名函数支持不同参数类型：

```cpp
void Swap(int& x, int& y);
void Swap(double& x, double& y);
void Swap(char& x, char& y);
```

但是如果类型很多，就要写很多份。

模板则是：

```cpp
template <class T>
void Swap(T& x, T& y);
```

只写一份，让编译器根据类型生成不同版本。

所以可以这样理解：

```cpp
函数重载：程序员手动写多个版本
函数模板：程序员写一份模板，编译器生成多个版本
```

------

## 十一、小结

本篇主要学习了函数模板的基本用法。

需要记住：

1. 模板用于编写和类型无关的通用代码；
2. 模板体现的是泛型编程思想；
3. 函数模板使用 `template <class T>` 或 `template <typename T>` 声明；
4. `T` 是类型参数，可以代表不同类型；
5. 函数模板可以减少重复代码；
6. 编译器会根据实参类型推导模板参数；
7. 模板参数可以有多个；
8. `typename` 和 `class` 在模板参数声明中基本等价；
9. 模板不是万能的，传入类型必须支持模板函数中使用的操作；
10. 函数模板可以看作是让编译器帮我们生成不同类型版本的函数。

函数模板是后面学习 STL 的基础。像 `vector<int>`、`stack<double>` 这些容器，本质上都离不开模板。
